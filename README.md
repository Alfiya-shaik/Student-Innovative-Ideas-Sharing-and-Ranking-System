# Student Innovative Ideas Sharing and Ranking System

---

## **Description**

This project is developed as part of our final year project. The main aim of this system is to provide a platform where students can submit their innovative ideas for different events and get them evaluated by faculty and other students.

In our college, students usually have many ideas, but there is no proper system to collect, evaluate, and manage them. So, we developed this web-based application to make the process simple, organized, and effective.

---

## **Features**

- Idea submission by students
- Viewing and searching ideas
- Voting system (Like/Dislike)
- Faculty remarks for improvement
- Leaderboard for top ideas
- Feedback system
- Admin management of users and events

---

## **Installation**

1. Install **NetBeans IDE**
2. Install **Apache Tomcat Server**
3. Install **MySQL Database**
4. Import the project into NetBeans
5. Add MySQL Connector JAR file
6. Configure database connection in the project

---

## **Usage**

1. Run the project using Apache Tomcat
2. Open browser and go to:  
   `http://localhost:8080/StudentInnovative/`
3. Select user role (**Admin / Student / Faculty**)
4. Perform operations like login, idea submission, voting, and feedback
